# Open Local Dictation v0.1.0

Released 2026-11-26.
First release notes: every change so far.

## New
- Optional mic button inside the Windows taskbar (Settings > Overlay): click to dictate, point at it to open the pill, drag to move it; it stays where you put it
- Microphone check: the tray icon and the taskbar button turn red when the microphone is unplugged, muted or blocked, and dictation shows a warning instead of starting
- Bubble overlay style, pill fits its content, restyled language menu
- Language menu in the small pill, inline overlay hints, search threshold
- Settings icons, scroll only card rows; fix duplicated dictation text
- Sideways-only and lockable overlay position
- Show the app icon in the settings title bar and header
- Overlay size choice, opacity and settings button
- Pinned and small overlay, themed tooltips, on-demand listening
- Choose which languages the overlay menu lists, recolour app icon green
- Initial Open Local Dictation app

## Other
- Pill header grows to fit the destination app name

## Install
- **Setup** (installs for all users into Program Files, asks for administrator rights): `Open-Local-Dictation-0.1.0-setup.exe`
- **Portable**: unzip `Open-Local-Dictation-0.1.0-portable.zip` anywhere and run `Open Local Dictation.exe`
