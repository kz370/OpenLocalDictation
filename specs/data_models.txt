DATA MODELS — Open Local Dictation v0.1.0
=========================================
All wire types are camelCase JSON. Rust definitions are in src-tauri/src, TypeScript mirrors in src/types.ts.

Settings (settings.rs, stored in <data>\settings.json; unknown/missing fields fall back to defaults; sanitize() runs on load and save)
  model                string   ""                      "" = best available; else a catalog id (whisper-tiny|base|small) or "custom:<folder path>"
  modelsDir            string   ""                      "" = <data>\models; set only by models_set_dir
  device               string   "gpu"                   "gpu" | "cpu"; GPU only takes effect once the CUDA pack is installed and the app restarted
  language             string   "auto"                  "auto" or a Whisper language code (lower case)
  shownLanguages       string[] []                      language codes listed in the overlay menu; empty = all (deduped on sanitize)
  microphone           string?  null                    null = system default input
  shortcut             string   "CommandOrControl+Alt+Space"
  mode                 string   "hold"                  "hold" | "toggle"
  insertMethod         string   "type"                  "type" | "paste"
  addTrailingSpace     bool     true
  reviewBeforeInsert   bool     true
  startWithOs          bool     false
  theme                string   "system"                "system" | "light" | "dark"
  vadThreshold         f32      0.6                     clamped 0.2 .. 0.95
  silenceMs            u32      800                     clamped 300 .. 3000 (VAD min silence = utterance boundary)
  autoStopSilenceSecs  u32      8                       0 = never; max 120
  overlayX / overlayY  i32?     null                    last dragged card position, physical px
  overlayPinned        bool     false                   overlay stays on screen, always on top; idle (mic closed) until shortcut or mic button
  overlayMiniWidth     u32      400                     small overlay width, logical px, 320-800 (dragged on its right edge)
  overlayOrbShift      i32      0                       bubble style: mic circle offset from the window center, logical px (clamped -2000..2000)
  overlaySizeLocked    bool     false                   no resize handle on the small overlay
  overlayStyle         string   "pill"                  small overlay look: pill | bubble (mic circle, pill above on hover/use)
  languageModels       map<string,string> {}            model id per language code; a language without an entry (and "auto") uses `model`; empty/"auto" keys and empty ids are dropped by sanitize
  taskbarWidget        bool     false                   mic button inside the Windows taskbar (bottom taskbar only); the pill opens above it, and the app's own floating circle/pill is not shown while it is on
  taskbarWidgetX       i32?     null                    taskbar button position: logical px from the taskbar's left edge; null until first placed, then fixed (set by dragging or by the first default placement), clamped 0 .. 16000
  overlayHorizontalOnly bool    true                    overlay drags sideways only and stays just above the taskbar (y is re-docked on show)
  overlayPositionLocked bool    false                   overlay cannot be dragged
  overlayShowSettings  bool     true                    gear button in the overlay header
  overlayOpacity       u32      100                     overlay background opacity, percent, 30-100
  overlayLayouts       string   "small"                 "small" | "large" | "both": which overlay sizes may be used
  overlayMini          bool     false                   current size when overlayLayouts is "both" (400x68 pill; review editor floats above it)

On-disk layout
  <models root>/stt/<catalog id>/{encoder.int8.onnx, decoder.int8.onnx, tokens.txt, .complete}   (root named "stt" -> <root>/<id>)
  <models root>/<any folder>/ or <models root>/stt/<any folder>/ holding encoder*.onnx + decoder*.onnx + *tokens.txt and NO file with "joiner" in its name  ->  custom model
  A catalog id counts as installed when its folder has .complete OR looks like a valid Whisper folder (either layout)
  <data>\vad\silero_vad.onnx           embedded in the exe (629 KB), written on start
  <data>\settings.json
  <data>\gpu\cuda-1.13.8\*.dll         CUDA pack + a copy of the exe; <data>\gpu\launcher (path of the installed exe); <data>\gpu\starting (crash guard)
  <logs>\local-dictation.<date>.log    daily, 7 kept
  <data> = %APPDATA%\com.localdictation.app

Model selection (ModelStore::resolve)
  1) settings.model if it is an installed catalog id   2) a custom model with that id
  3) the largest installed catalog model (small > base > tiny)   4) the first custom model (alphabetical)

CUDA pack (gpu.rs)
  PACK_VERSION 1.13.8 (must equal the sherpa-onnx crate version). Required files: onnxruntime.dll, onnxruntime_providers_cuda.dll,
  sherpa-onnx-c-api.dll, cudart64_12.dll, cublas64_12.dll, cublasLt64_12.dll, cudnn64_9.dll (+ the other cuDNN parts).
  Sources: sherpa-onnx GPU archive from GitHub releases; cudart / cuBLAS / cuDNN from NVIDIA redistributables. Total ≈ 1.7 GB.
  Reuse: %APPDATA%\com.localassistant.app\gpu\cuda-1.13.8 (Open Local Assistant) is hard-linked, copied when linking fails.

Constants
  Audio: 16 kHz mono, 100 Hz one-pole high-pass, level = RMS mapped -60..0 dB, spectrum = 24 log bands 80 Hz..4 kHz.
  MIN_AUDIO_MS 350 · MAX_RECORDING 300 s · VAD window 512 samples · utterances are at most 20 s (VAD max_speech_duration), so Whisper never needs chunking.
  Typing: 16 ms per character (measured; faster drops characters), review focus delay 150 ms.
  Overlay card 480 x 176 logical px; menu room 240 px above/below; settings window 780 x 656.
  Overlay linger after a take: 800 ms (inserted), 2200 ms (message).

TaskbarStatus (event taskbar://status, command taskbar_widget_status)
